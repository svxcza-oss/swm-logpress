# Definition — McNemar's Test 
McNemar's Test is a non-parametric statistical test for comparing two paired proportions measured from the same subjects under two conditions or at two time points. It tests whether the marginal proportions of a binary outcome are equal by focusing exclusively on the subjects whose outcome changed — the discordant pairs.(멕네마 검정은 동일한 대상자에게서 두 조건 또는 두 시점에서 측정된 두 쌍의 비율을 비교하기 위한 비모수 통계 검정이다. 이 검정은 결과가 변한 대상, 즉 불일치 쌍에만 집중하여 이진 결과의 주변 비율이 동일한지 여부를 검증.)

- McNemar, Q. (1947). "Note on the sampling error of the difference between correlated proportions." Psychometrika, 12(2), 153–157.
- https://statisticsfundamentals.com/hypothesis-testing/mcnemars-test/ (위 설명 출처)

* 핵심 - 왜 불일치쌍만 보는것인가?
- 두 모델의 '성능 차이'를 구하려면?
- 얼마나 '다른가'를 알고 싶을땐, 똑같이 행동한 데이터를 비교하는것은 '차이'증명에는 수학적으로 0의 가치. (같은것은 소거.)
- 즉, 둘다 1 or 둘다 0인 경우는 두 모델을 비교

# 실제 비교 과정

                   baseline 살림(1)   baseline 버림(0)
LogPress 살림(1)      (1,1) → a        (1,0) → b
LogPress 버림(0)      (0,1) → c        (0,0) → d

LogPress 보존율 = (a+b) / n
baseline 보존율 = (a+c) / n

차이 = (a+b)/n − (a+c)/n = (b−c)/n

## 멕네마 검정 (McNemar's Test) 핵심 요약

### 1. 직관적 원리 (소거법)
* **일치 쌍 ($a, d$)**: 둘 다 보존($a$)하거나 둘 다 제거($d$)한 경우. 난이도가 너무 쉽거나 어려워 두 모델의 성능 차이를 알 수 없으므로 계산에서 제외함.
* **불일치 쌍 ($b, c$)**: 한 쪽만 보존하고 다른 쪽은 제거된 엇갈린 경우. 오직 이 데이터에서만 두 모델의 실력 차이가 드러남.

### 2. 가설 검정 로직
귀무가설(두 모델의 실력이 동일함)이 참이라면, 엇갈린 쌍이 어느 한쪽 모델로 쏠릴 확률은 정확히 반반(50:50)이어야 함. 
즉, 총 $b+c$개의 불일치 쌍을 대상으로 동전 던지기를 하는 것으로 간주하여, 특정 결과($b$ 또는 $c$)가 유의미하게 한쪽으로 쏠렸는지를 확인하는 과정임.

### 3. 검정 통계량
$$ \chi^2 = \frac{(b-c)^2}{b+c} $$
* **자유도 (df)**: 1
* **분모가 $b+c$인 이유**: 동전을 총 $b+c$번 던진 것과 같은 '전체 시행 횟수'를 의미하기 때문.

### 4. 주의사항
불일치 쌍의 총합($b+c$)이 너무 적은 경우(계약서 §4의 임계치 참고), 카이제곱 분포로의 근사가 깨질 수 있음. 이때는 근사치를 사용하는 대신 **이항 정확 검정(Binomial Exact Test)**으로 전환하여 평가해야 함.

# BH-FDR - p값 활용

# Definition - BH-FDR
The common approach to the multiplicity problem calls for controlling the familywise error rate (FWER). This approach, though, has faults, and we point out a few. A different approach to problems of multiple significance testing is presented. It calls for controlling the expected proportion of falsely rejected hypotheses — the false discovery rate. This error rate is equivalent to the FWER when all hypotheses are true but is smaller otherwise. Therefore, in problems where the control of the false discovery rate rather than that of the FWER is desired, there is potential for a gain in power. A simple sequential Bonferronitype procedure is proved to control the false discovery rate for independent test statistics, and a simulation study shows that the gain in power is substantial. The use of the new procedure and the appropriateness of the criterion are illustrated with examples. (다중 유의성 검정 문제에 대한 새로운 접근법을 제시한다. 기존 방식 FWER, 본페로니 같은것들은 유의미한 결과까지 버려버린다. 이 논문에서는 새로운 접근법을 제시한다. 유의미하다고 발견한 결과물들 중, 가짜가 섞여 있는 비율만 통제하는 방식이다. 기존방식에서는 유의미한 데이터들까지 버리는것을 방지할 수 있다. 방법은 p값들을 줄세워 자르는 단순한 방식이다.)

- Benjamini, Y., & Hochberg, Y. (1995). "Controlling the False Discovery Rate: A Practical and Powerful Approach to Multiple Testing." JRSS-B, 57(1), 289–300. DOI: 10.1111/j.2517-6161.1995.tb02031.x
- https://academic.oup.com/jrsssb/article/57/1/289/7035855

### 무엇을 통제하나 (FDR의 정의)
* V = 거짓 기각 수, R = 총 기각 수
* FDR = $E\left[ \frac{V}{R} \right]$ = 내가 "유의하다"고 고른 것들 중 가짜의 기대 비율
* Bonferroni처럼 "가짜를 하나도 안 내겠다(FWER)"보다 느슨해서 검정력이 높다 — "고른 것 중 가짜 비율을 5% 이하로만 유지하겠다"는 완화된 목표.

### 절차: 정렬 → 순위별 문턱
1. raw p값을 오름차순 정렬: $p_{(1)} \le p_{(2)} \le \dots \le p_{(m)}$
2. 다음을 만족하는 가장 큰 $k$를 찾는다: 
   $$ p_{(k)} \le \frac{k}{m}\alpha $$
3. $p_{(1)} \dots p_{(k)}$ 를 모두 기각.

### 직관
**가장 작은 p값은 가장 엄격한 문턱($\alpha/m \approx \text{Bonferroni}$)**을 넘어야 하고, 순위가 뒤로 갈수록 문턱이 $(k/m)\cdot\alpha$로 점점 느슨해진다. "진짜 유의한 게 많다면 그만큼 관대해도 된다"는 논리.

"p값을 재료로"가 무슨 뜻이냐

BH는 실험을 다시 돌리지 않는다. McNemar가 내놓은 p값 목록만 받아서, "이 중 어디까지를 진짜 유의로 볼까"의 합격선만 다시 긋는다. 원자료는 손도 안 댄다.

시험으로 치면 — 채점(McNemar)은 이미 끝났고, BH는 그 점수표만 보고 등수를 매겨 합격선을 정하는 감독관이다. 그래서 채점기 다음 단계로 깔끔히 분리된다.
