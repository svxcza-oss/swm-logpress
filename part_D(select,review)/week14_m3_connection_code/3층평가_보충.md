# 3층 평가 — 출력 충실도

> 압축본이 원본과 **"같게 판단하나"**를 본다.
> LogPress · Role D (리드·평가)

---

## 1. 3층 평가의 목적

압축본을 넣었을 때와 원본(full)을 넣었을 때, **모델의 출력 "분포"가 거의 같은가?**

### 왜 필요한가
- RCA 정답률은 프론티어 모델도 **3.9~12.5%**로 둔하다 → 정답률로는 압축 차이가 안 보인다.
- 최종 답(가장 높은 후보)이 "메모리 vs 디스크"처럼 같아 보여도, 그 뒤 **확률 분포는 뭉개질 수** 있다.
- 그래서 **"답이 같나"(X)가 아니라 "확률 지형이 같나"(O)**를 본다 — 그래서 3층이 예민하다.

### 세 층의 역할 분담
- **1층** = 입력 보존(원인 잘 남기나)
- **2층** = 비용(메모리·속도)
- **3층** = 출력 충실(원본과 같게 판단하나)

> RCA 정답률은 **"조연"** — "보존이 헛되지 않았다"만 최소 확인한다. 진짜 판단은 **1층(보존율) + 3층(출력 충실도)**이 맡는다.

---

## 2. 왜 세 가지 지표인가

하나로는 한 면만 본다 — 세 지표가 보는 **"넓이"가 달라 서로를 보완**한다. (점 → 평균 → 분포 전체)

| 지표 | 보는 넓이 | 무엇을 |
|---|---|---|
| ① log-probability | **"점"** | 정답 토큰 한 개의 확신 |
| ② perplexity | **"평균"** | 시퀀스 전체의 평균 품질 |
| ③ KL divergence | **"분포 전체"** | 출력 분포 전체의 모양 |

- 시야가 **점(log-prob) → 평균(perplexity) → 분포 전체(KL)**로 넓어진다.
- 셋 다 NLP 표준 지표이고, KV 압축 논문들이 품질 열화를 보고할 때 쓰는 척도다 → **"왜 이 지표?" 방어 부담이 적다.**

## 3. 정답 확률 p 는 어떻게 나오나

입력 → [모델] → 로짓(logits) → [softmax] → 확률분포 → 정답 토큰 자리 값 = **p**

1. **로짓** — 모델이 forward 한 번 하면, 어휘 전체(Qwen ~15만 개)에 원시 점수를 바로 내놓는다. 모델의 네이티브 출력 (**역산 아님**).
2. **softmax** — 로짓을 0~1 확률로 변환(합=1). `pᵢ = e^(logitᵢ) / Σ e^(logitⱼ)`. 학습 파라미터 없는 한 방향 공식.
3. **읽기** — 정답 토큰 위치의 확률을 꺼낸다 = p. 그 로그값이 log p.

```
예시)  logit [디스크 2.0, 메모리 1.0, 네트워크 0.5]  →  softmax  →  p [0.63, 0.23, 0.14]
정답이 '디스크'면  p = 0.63,  log p = −0.46
```

> **역산 아님** — 모델이 글자를 고를 때 이미 계산해 둔 값을 읽을 뿐. 글 생성을 끝까지 안 해도 됨: 로짓만 뽑으면 끝 → 그래서 3층 측정이 가볍다.

## 4. 세 가지 지표

### ① log-probability (로그 확률)

| 항목 | 내용 |
|---|---|
| **정의** | 모델이 정답 토큰에 매긴 확률 p 의 로그값 = log p |
| **방향 / 범위** | log p ≤ 0. 0에 가까울수록(= p가 1에 가까울수록) 좋다 ↑ |
| **무엇을 보나** | 압축본의 "정답 확신"이 원본만큼 유지되는가 |

> **성공 판정:** 절대 통과 숫자는 없다(상대 지표). 압축본 log p ≈ 원본 log p (차이 Δ ≈ 0)이면 충실. baseline보다 Δ가 작으면 우위.

### ② perplexity (혼란도)

| 항목 | 내용 |
|---|---|
| **정의** | PPL = exp( 평균 음의 로그우도 ) = exp( −(1/N)Σ log p ). "모델이 얼마나 헷갈렸나" |
| **방향 / 범위** | 하한 1. 낮을수록 좋다 ↓ (완벽하면 1) |
| **무엇을 보나** | 압축본 전체 출력이 원본만큼 자연스러운가(전체 평균 품질) |

> **성공 판정:** 언어모델 평가의 정석 지표. 성공 = 원본(full) 대비 PPL 증가가 미미(곡선이 원본에 붙어감) + baseline보다 덜 증가.

### ③ KL divergence (분포 차이)

| 항목 | 내용 |
|---|---|
| **정의** | D(P‖Q) = Σ P(x)·log( P(x)/Q(x) ). P = 원본 출력분포, Q = 압축본 출력분포 |
| **방향 / 범위** | ≥ 0. 0이면 두 분포가 완전히 같다 → 0에 가까울수록 좋다 |
| **무엇을 보나** | 출력 "분포 전체"가 원본과 같은 모양인가 (주의: 비대칭 — 원본 P를 기준으로 고정) |

> **성공 판정:** KL → 0 (분포 일치) + baseline보다 작으면 우위. 최종 답이 같아 보여도 분포가 뭉개지면 KL이 잡아낸다.

---

## 5. 성공 판정 — 공통 원리

세 지표 모두 **"마법의 통과 숫자"는 없다.** 성공은 두 가지를 함께 본다.

1. **원본에 붙는다** — 압축본 지표가 원본(full)과 차이 ≈ 0. (log-prob Δ≈0 · ΔPPL 작음 · KL→0)
2. **baseline보다 충실하다** — 같은 압축률에서 우리 압축기가 baseline보다 원본에 더 가깝다.

### 1·2층과 같은 철학
- 임의의 % 기준이 아니라 **"원본 대비 / baseline 대비" 상대 비교** (1층 보존율 파레토, 2층 비용과 동일한 사고).
- 측정법: 원본(full) 넣은 출력 vs 압축본 넣은 출력을 **같은 모델·같은 프롬프트**로 비교.
- **정답 라벨이 필요 없다** — "모델 vs 모델 자기 자신" 비교라 모델 출력을 그대로 측정 대상으로 쓴다.
- 여러 번 측정한 값의 흔들림은 **부트스트랩 신뢰구간**으로 확인 (1·2층과 동일).
