# v7 프리즈 부속서 — 지표별 '의도' / 무엇을 보여주는가?

> **전체 주제:** "어텐션이 alert(원인) 줄을 잘 잡는가"를 검증한다.
> 8개 지표는 이 주장에 올 수 있는 **반박을 각각 막는 방어 도구**다.
> 분류 기준 = **"이 지표가 어떤 반박을 막는가."**
>
> 각 지표: ① 왜 필요(막는 반박) · ② 왜 이 방법 · ③ 충족했나
> 시점 태그: **[사전]** 결과 보기 전 고정(반칙 방지) · **[분석]** 나중에 별도 분석

---

## Ⅰ. 통계적 방어 — "우연이거나 반칙 아니야?"

### 1. 필요한 pair 수 (검정력) **[사전]**
- **① 막는 반박:** "표본이 부족해서 신호를 놓친 것 아냐?"
- **② 왜 이 방법:** 짝(alert-normal)을 비교해야 "더 크다"를 말할 수 있다. 가짜 데이터로 여러 번 돌려 필요한 수를 역산(검정력 0.8 = 관례).
- **③ 충족했나:** 어텐션값을 받아 실제 측정해봐야 확인. (현재 GPU 대기)

### 2. Delta 최소 임계값 (합격선) **[사전]**
- **① 막는 반박:** "기준을 결과 보고 유리하게 정한 것 아냐?(반칙)"
- **② 왜 이 방법:** 결과 전에 미리 고정. 파일럿 흩어짐 × 0.5 (Cohen medium, 통계 관례)로 근거 있게.
- **③ 충족했나:** 어텐션값 측정 후, confirmatory Delta가 이 선을 넘는지 확인.

### 3. Ranking 주지표 **[사전]**
- **① 막는 반박:** "여러 지표 중 유리한 걸 고른 것 아냐?(반칙)"
- **② 왜 이 방법:** 라인 간 불균형 때문에 순위로 비교. 주지표는 rank-difference(normal 등수 − alert 등수) 하나로 고정 — 짝 구조와 가장 잘 맞아서.
- **③ 충족했나:** 후보들에 순위를 매길 수 있으므로 충족.

### 4. 순열검정 사양 **[사전]**
- **① 막는 반박:** "우연히 답이 좋게 나온 것 아냐?"
- **② 왜 이 방법:** 라벨을 섞는 모든 우연의 경우를 다 테스트. 분포 가정이 필요 없어 가장 정직(표본 작아도 안전). B=5,000·양측·α0.05.
- **③ 충족했나:** 실제로 돌려봐야 확인. 사양을 미리 고정해 두는 게 역할.

### 5. Bootstrap 사양 **[사전]**
- **① 막는 반박:** "이 결과가 불안정한(우연히 나온) 것 아냐?"
- **② 왜 이 방법:** 1번(짝 수)과 다르다 — 이건 결과의 **안정성**을 잰다. 짝을 다시 뽑아도 Delta가 계속 양수인지. BCa는 표본 작을 때 치우침 보정.
- **③ 충족했나:** 판정 기준(95% CI 하한 > 0)을 미리 세워둠.

### 6. 다중비교 **[사전]**
- **① 막는 반박:** "지표를 여러 개 보다가 하나 걸린 것 아냐?(반칙)"
- **② 왜 이 방법:** 4번이 "이 하나가 우연이냐"라면, 6번은 "여러 개 보다 우연히 걸림"을 막음. 판정 지표를 1개로 고정 → family=1 → 보정 불필요.
- **③ 충족했나:** 판정에 쓰는 지표가 정말 1개로 고정됐는지 확인.

---

## Ⅱ. 인과적 방어 — "alert라서가 아니라 딴 이유 아니야?"

### 7. 템플릿 누수 통제 **[분석]**
- **① 막는 반박:** "alert라서가 아니라, 그냥 드문 템플릿이라 어텐션이 몰린 것 아냐?"
- **② 왜 이 방법:** normal 짝을 템플릿 희귀도까지 맞추거나, 안 본 템플릿(홀드아웃)으로 검증.
- **③ 충족했나:** 안 본 템플릿에서도 Delta가 살아남는지 확인.

### 8. 싼 baseline 대비 **[분석]**
- **① 막는 반박:** "어텐션 안 써도 rarity+position 같은 싼 신호로 되잖아?"
- **② 왜 이 방법:** 구하기 쉬운 신호와 어텐션을 직접 대결. 어텐션이 이겨야 쓸 가치가 증명됨.
- **③ 충족했나:** 어텐션 Delta가 싼 신호를 이기는지 확인.

---

## 한 줄 정리

- 8개 지표 = "어텐션이 alert를 잘 잡는다"는 주장에 올 **반박을 막는 방어들.**
- **Ⅰ 통계적 방어(1~6)** = "우연/반칙 아니다" · **Ⅱ 인과적 방어(7~8)** = "딴 이유 아니다."
- 시점: **[사전]**(1~6)은 결과 전 고정 = 반칙 방지 / **[분석]**(7~8)은 나중 별도 분석.
- 헷갈리기 쉬운 구분: **1번 = 몇 개 필요 / 5번 = 얼마나 안정적** (서로 다름).
