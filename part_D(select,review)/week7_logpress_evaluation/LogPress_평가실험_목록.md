# LogPress 압축기 평가 — 실험 목록 (D) 
* c와 의견 일치

> 기존 평가(1층 보존율 + 2층 K지선다 + McNemar/BH)는 "잘 되나"를 본다.
> 이 문서는 그 위에 얹는 두 층 — **① 압축기를 여러 각도로 뜯어보기**, **② 약점을 일부러 찔러 깨보기** — 를 정리한다.
> 다음 주 C 설계 평가 지원 때 사용.

---

## A. 압축기 자체 평가 — 여러 각도로 뜯어보기

보존율 하나로는 압축기를 다 판단 못 한다. 아래 축으로 나눠 본다.

| # | 축 | 무엇을 보나 | 왜 필요 |
|---|---|---|---|
| A1 | **원인 보존율** | 압축 후 원인 줄이 살았나 (기본) | 압축기의 기본 성능 |
| A2 | **압축률별 곡선·한계점** | 압축률 50→90% 올리며 보존율이 어디서 무너지나 (cliff) | 단일 숫자가 아니라 "어디까지 압축해도 안전한가" |
| A3 | **최악 케이스** | 평균 말고, 제일 안 좋았던 케이스의 보존율 | 운영 관점 — 평균 95%여도 핵심 장애서 0%면 재앙 |
| A4 | **놓친 원인 프로파일** | 버려진 원인 줄들의 공통 특징 (레벨·위치·길이) | 자화자찬 대신 실패 분석 → 약점 정확히 파악 |
| A5 | **안정성** | 같은 로그를 여러 번·여러 모델로 돌려 일관되나 | 믿을 만한가 (재현성) |

→ **A1은 기존, A2~A5가 새로 추가하는 관점.** 며칠 전 "보존율 5방향 꺾기"가 이것.

## B. 약점 저격 실험 (Stress Test) — 일부러 깨보기

기본 평가가 "잘 되나?"라면, 이건 **"언제 깨지나?"** 를 본다.
C 방법(어텐션 기반)의 약점 3개를 각각 겨냥.

### B1. 모델 교체 실험 — "LLM 의존" 약점 저격
- **찌르는 약점:** 어텐션은 모델마다 다르다 → 모델 바뀌면 결과도 바뀔 수 있다.
- **어떻게:** 같은 압축을 **Qwen 어텐션 vs Llama 어텐션**으로 각각 → 원인 보존율이 일치하나.
- **해석:** 일치하면 "모델 안 타는 튼튼한 방법"(강점). 확 다르면 "모델 의존 심각"(약점 입증).
- 이미 C 피드백에 "두 백본에서 재현" 써둔 것을 정식 실험으로.

### B2. 원인 위치 옮기기 — "위치 편향" 약점 저격
- **찌르는 약점:** S_j가 앞쪽 줄을 구조적으로 편애한다.
- **어떻게:** 원인 줄만 앞/중간/뒤로 옮기고(나머지·인과 흐름은 유지) 보존율 비교.
- **해석:** 위치 따라 보존율이 크게 달라지면 → "원인이 아니라 위치를 보고 있다" 폭로.
- **주의:** 로그 전체를 뒤죽박죽 섞으면 인과 흐름까지 깨져서, 위치 편향인지 인과 붕괴인지 구분 불가. → **원인 줄 위치만** 바꾸는 "깨끗한 버전"으로.

### B3. 일반화(데이터 교체) 실험 — "데이터 의존" 약점 저격
- **찌르는 약점:** 특정 데이터에서만 되는 요행일 수 있다.
- **어떻게:**
  - 시스템 다른 데이터에서 각각 (Thunderbird / Nezha / +BGL·HDFS)
  - **한 데이터로 튜닝 → 다른 데이터로 테스트** (과적합 폭로)
- **해석:** 다 통하면 "일반적". 특정 데이터만이면 "요행". 튜닝셋만 잘 되면 "과적합".
- **제약:** 지금 데이터 적음(Nezha 실데이터 2케이스) → 지금은 방향 확인까지, 본격은 데이터 추가 후. (로드맵 Q2 일반화 검증과 연결)

### (추가 후보)
- **B4. 노이즈 추가:** 무관한 로그를 잔뜩 섞어도 원인을 잡나.
- **B5. 극단 압축:** 90%+ 세게 압축해도 버티나. (A2 곡선과 연결)

## C. 평가 틀은 재활용된다 (중요)

- 위 실험 전부 **새 평가 틀이 필요 없다.** 재는 건 항상 "원인 줄이 살았나(1층) / LLM이 맞히나(2층)"라, **압축기가 뭐로 만들어졌든 동일하게 적용**된다.
- 압축기(어텐션안/위치안/대안)만 갈아끼우고, **기존 보존율·K지선다·McNemar를 그대로** 돌리면 된다.
- 즉 **비교 대상만 늘리는 것.** ablation에 조합 추가하는 것과 같음.

```
어텐션 압축기  ┐
위치 압축기    ├→ [살릴 줄 목록] → 같은 평가(1층+2층+스트레스) → 비교
대안(보너스)   ┘
```
