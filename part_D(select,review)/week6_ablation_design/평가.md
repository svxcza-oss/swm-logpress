

**1차 실험 판정 기준 (C 실험 설계에 붙이는 부분)**

**① 구분되는가 — AUC (= Mann-Whitney U)**
- Alert 500개 vs Normal 500개 S_10을 AUC로 비교.
- AUC가 0.5에서 벗어날수록 두 집단이 구분됨. (킬스위치에서 위치 AUC 잰 것과 **같은 방법**)
- 방향 무관 — 0.5보다 크든 작든, 벗어나기만 하면 됨 (C 문서의 "높아도 낮아도 된다"와 일치)

**② 충분히 큰가 — 효과 크기 |AUC − 0.5|**
- 표본이 500개라 아주 작은 차이도 "유의"로 나올 수 있음 → 크기 문턱을 둠.
- 킬스위치 때 쓴 **|AUC − 0.5| ≥ 0.15** 기준을 그대로 가져옴.

**③ 우연 아닌가 — p값 + BH 보정**
- Mann-Whitney p값으로 유의성 확인.
- Layer 구간(Early/Middle/Late) 여러 번 검정하니까 → **BH 보정**으로 가짜 양성 통제.

**→ 통과 조건:** AUC가 0.5에서 유의하게 벗어나고(①③), 그 크기가 기준 이상(②)이면 "질문 없는 어텐션이 alert/normal을 구분한다" = 1차 성공.
