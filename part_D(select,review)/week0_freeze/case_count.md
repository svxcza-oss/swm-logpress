### 🧮 표본 수 산출 (Sample Size Calculation)
코헨의 효과 크기(Medium Effect) 기준을 적용한 그룹당 필요 표본 수($n$) 산출 공식:

$$
n = 2 \times \left( \frac{Z_{1-\alpha/2} + Z_{1-\beta}}{d} \right)^2
$$

위 공식에 설계된 실험 조건($\alpha = 0.05$, $Power = 0.8$, $d = 0.5$)을 대입하면 아래와 같이 약 64개라는 결론이 도출.

$$
n = 2 \times \left( \frac{1.96 + 0.84}{0.5} \right)^2 = 62.72 \approx 64
$$

--> 효과크기 d = 0.5, alpha = 0.05, power = 0.8이면 그룹당 약 64개 필요.
계산 자체는 정확하지만, 64 -> 300로 올리는 안전계수에는 근거가 없음.

### 📊 Hanley-McNeil AUC 분산 산출 공식
본 프로젝트는 모델의 성능 지표인 AUC의 통계적 유의성과 신뢰구간(Confidence Interval)을 도출하기 위해, Hanley와 McNeil(1982)이 제시한 분산($Var(A)$) 추정 공식을 채택하였음.

$$
Var(A) = \frac{A(1-A) + (n_1 - 1)(Q_1 - A^2) + (n_2 - 1)(Q_2 - A^2)}{n_1 n_2}
$$

위 수식의 구성 요소는 다음과 같이 엄밀하게 정의.
* $A$: 산출된 모델의 AUC (Area Under the Curve)
* $n_1$: 양성(Positive) 표본의 총 개수
* $n_2$: 음성(Negative) 표본의 총 개수
* $Q_1 = \frac{A}{2-A}$: 무작위로 추출한 2개의 양성 표본이 1개의 음성 표본보다 예측 점수가 높을 확률
* $Q_2 = \frac{2A^2}{1+A}$: 무작위로 추출한 1개의 양성 표본이 2개의 음성 표본보다 예측 점수가 높을 확률
